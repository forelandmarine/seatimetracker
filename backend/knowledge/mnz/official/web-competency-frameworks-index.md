# Competency frameworks (index page listing every certificate framework)

Source: https://www.maritimenz.govt.nz/seafarers/getting-certified/training/competency-frameworks/

Web page text captured 2026-10-25; site navigation, cookie text and contact boxes removed.

Maritime NZ has set competencies that must be achieved for each of the certificates. These align with international conventions and the maritime rules.

This page links to competency-framework documents for national certificates, STCW and STCW-F aligned certificates, and related endorsements.
