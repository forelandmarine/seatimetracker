# AMSA approved short courses

Source: https://www.amsa.gov.au/qualifications-training/training-organisations/amsa-approved-short-courses

A list of all our approved short courses.

STCW Short Courses STCW Convention, Chapter IV - Radio Communication and Radio Personnel

GMDSS course - STCW Code Section A-IV/2

STCW Convention, Chapter V - Special Training Requirements for Personnel on Certain Types of Ships

Regulation V/1

- Tanker Familiarisation (gas) - STCW Code Section A-V/1-2, Paragraph 1 and 2
- Tanker Familiarisation (oil and chemical) - STCW Code Section A-V/1-1, Paragraph 1 and 2
- Specialised Training for Oil Tankers - STCW Code Section A-V/1-1, Paragraphs 3 and 4
- Specialised Training for Chemical Tankers - STCW Code Section A-V/1-1, Paragraphs 5 and 6
- Specialised Training for Liquefied Gas Tankers - STCW Code Section A-V/1-2, Paragraphs 3 and 4

Regulation V/2

- Passenger Ships - STCW Code Section A-V/2, Paragraphs 3 and 4

STCW Convention, Chapter VI - Emergency, Occupational Safety, Security, Medical Care and Survival Functions Regulation VI/1

- Personal Survival Techniques - STCW Code Section A-VI/1, Table A-VI/1-1
- Fire Prevention and Basic Fire Fighting - STCW Code Section A-VI/1, Table A-VI/1-2
- Elementary First Aid - STCW Code Section A-VI/1, Table A-VI/1-3
- Personal Safety and Social Responsibilities - STCW Code Section A-VI/1, Table A-VI/1-4

Regulation VI/2

- Proficiency in survival craft and rescue boats, other than fast rescue boats - STCW Code Section A-VI/2, Section A-VI/2 Paragraphs 1-4, Table A-VI/2-1
- Proficiency in Fast Rescue Boats - STCW Code Section A-VI/2, Section A-VI/2 Paragraphs 7-10, Table A-VI/2-2

Regulation VI/3

- Advanced Fire Fighting - STCW Code Section A-VI/3 paragraphs 1-4, Table A-VI/3
- Basic IGF Code - STCW Code Section A-V/3 paragraph 1, Table A-V/3-1
- Advanced IGF Code - STCW Code Section A-V/3 paragraph 2, Table A-V/3-2
- Basic Polar Code - STCW Code Section A-V/4 paragraph 1, Table A-V/4-1
- Advanced Polar Code - STCW Code Section A-V/4 paragraph 2, Table A-V/4-2

Regulation VI/4

- Medical First Aid - Standard of competence for seafarers designated to take charge of medical care on board ship - STCW Code Section A-VI/4, Paragraphs 1-3, Table A-VI/4-1
- Medical Care - Standard of competence for seafarers designated to provide medical first aid on board ship - STCW Code Section A-VI/4, Paragraphs 1-3, Table A-VI/4-2

Regulation VI/5

- Ship Security Officer-Standard of competence - STCW Code Section A-VI/5, Paragraphs 1-4, Table A-VI/5

Regulation VI/6

- Security awareness training - STCW Code Section A-VI/6, Paragraph 4, Table A-VI/6-1
- Designated security duties - STCW Code Section A-VI/6, Paragraph 6, Table A-VI/6-2
