  Remove or reassign a proxy

  The My Applications dashboard is where you manage proxy access. Only you, the mariner, can remove or reassign a proxy.

  Removing a proxy
  Go to the relevant application and select Remove Proxy. This triggers the
  proxy removal workflow and notifies the proxy that their services are no
  longer required for the application.

  Reassigning a proxy
  You can reassign an application to a different proxy without removing the
  existing one first. Select Reassign Proxy, enter the details of the new proxy,
  and confirm. The new proxy replaces the existing one.
