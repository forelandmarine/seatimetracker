  Advanced Polar Code Operations Revalidation (RENEWAL)  PL 02-18

  Code Operations;
  OR,
2.  Evidence of a qualified instructor who has taught a USCG approved or accepted
  Advanced Polar Code Operations course at least twice in the  previous 5 years from
  date of application;
  OR,
3.  60 days seagoing service as an management level (Master or Chief Mate) deck
  officer with the previous 5 years operating within polar waters.
Basic and Advanced Polar Code Notes  :
1.  Sea service must be documented in accordance with 46 CFR 10.232 and should
  include the number of days served and capacity served on a vessel operating in polar
  waters.
2.  Service in the capacity of Ice Pilot may be accepted as long as the appropriate STCW
  is currently held.
3.  Polar Waters means Artic waters (greater than 60N) and/or the Antarctic waters
  (greater than 60S).
4.  Revalidation of Advanced Polar Code also meets Basic Polar Code  Revalidation.
